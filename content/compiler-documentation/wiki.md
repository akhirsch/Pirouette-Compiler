The [student github page](https://github.com/akhirsch/Pirouette-Compiler) contains [a wiki](https://github.com/akhirsch/Pirouette-Compiler/wiki).
This wiki is used for a few purposes.

# Onboarding Documents

The wiki contains a number of onboarding documents, designed to help students get started with the project.
Since most of the ELR students who join this project have no experience with compilers, these include some basic information on compilers.
They also contain best practices for using the tools, including bisect and a Raspberry Pi cluster used internally for testing.

# Policies

The wiki describes a number of project-specific policies for ELR students.
It also has some templates in order to help students comply with these policies.
These include things like code reviews, branch names, and more.

# Design Docs

Each new feature needs a design doc, which must be approved by a professor or similar before code can be featured.
These describe what will be done, why, and how.
They also describe foreseen tradeoffs.

By the time any code is ready for consumption, any relevant information from the design doc should be reflected here.

# Meeting Notes

Finally, meeting notes are kept on the wiki.
